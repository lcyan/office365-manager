# Go 版重写实施计划（office365-manager）

## 已确认的决策
- **镜像**：沿用 `ghcr.io/lcyan/office365-manager`，CI 发布逻辑不变；端口 5000 不变。
- **环境变量**：全新命名，不做兼容——`SESSION_SECRET`（必填，缺失启动即失败；本地开发 `DEV_MODE=1` 时生成临时密钥并警告）、`CONFIG_FILE`（默认 `/app/config.json`，compose 继续设为 `/app/data/config.json`）。
- **代码位置**：Go 标准布局接管仓库根目录，Python 版（app.py、templates/、tests/、requirements.txt）全部删除，只留 git 历史。
- **功能**：完全对等——组织管理（增/删/改/测/API 批量导入/CSV 模板）、仪表盘、组织概况、用户分页搜索/角色筛选、用户详情、改密/启停/角色切换、订阅多选分配撤销、添加/删除用户。URL 结构与现有一致。
- **UI**：html/template + 按 **shadcn/ui 设计规范**用纯 CSS 实现其设计体系（design tokens CSS 变量 + 组件样式），服务端渲染、不引入 React/JS 框架；中文界面保留；支持亮/暗色（`prefers-color-scheme`）。
- **config.json**：新格式（带 `version` 字段）；启动时若检测到旧版格式自动迁移——组织原样迁入，旧 SHA-256 密码哈希保留至首次登录成功后透明升级为 argon2id（约 30 行，保护 pull :latest 的存量用户；如不需要可去掉这一步）。

## 目录结构
```
cmd/server/main.go            # 装配依赖、启动 HTTP（永不启用 debug 控制台）
internal/config/              # 配置结构、加载校验、原子写入(tmp+rename, 0600)、旧版迁移
internal/auth/                # argon2id 哈希+旧哈希校验迁移、登录限速(每IP令牌桶)
internal/graph/               # Graph 客户端：token 缓存/刷新/401重试一次、OData 统一转义、
                              #   user_id GUID 校验、类型化错误、$count+$top/$skip 分页、nextLink 跟随
internal/web/                 # session(scs)、中间件(登录强制/CSRF/安全头)、渲染、各 handler
internal/background/          # 延迟删除/角色分配重试（goroutine，slog 记录最终结果）
internal/licenses/            # SKU 映射（内嵌 + 可选外部覆盖文件）
web/templates/                # base + 9 个页面（shadcn 风格）
static/                       # 新 style.css（shadcn tokens）+ favicon.svg
```
依赖仅 3 个：`golang.org/x/crypto`（argon2）、`golang.org/x/oauth2`（client credentials 取 token）、`github.com/alexedwards/scs/v2`（会话，HttpOnly+SameSite=Lax）。路由用 Go 1.22+ 标准库 `net/http` 方法路由；模板/静态资源 `go:embed` 打进单二进制。

## 19 个问题的修复方式（映射）
1. 全局注入 → 显式 view model，无 `app.run` 路径，main 只起生产式 server。
2. 删除用户改为**先删用户**；仅当返回 insufficient privileges 时才移除角色（逐个检查结果）再重试一次；不再预剥离。移除结果如实报告。
3/6. Graph 错误统一为类型化错误，所有 GET 页面把错误渲染成明确横幅，不再静默空表。
4. 角色筛选改用 roleAssignments `$expand=principal`，组/服务主体显示为组，不再整页报错。
5/17. 分页改为 `$count=true + $top/$skip` 同响应自带总数，页码永远自洽；删除 nextLink 分页缓存（无锁共享缓存问题整类消失）。概况缓存保留 60s TTL + 写失效 + 版本号防回写。
7. CSV 导入先全量解析校验（容忍短行/编码错误并报行号），全部通过才原子落盘——不再出现半导入状态；错误列表截断防 cookie 超限。
8. roleAssignments 全部跟随 nextLink（$top=999 循环）。
9. update：PATCH 失败即中止角色变更并如实提示；角色枚举服务端校验，非法值报错。
10. 后台任务放弃时 slog warning 记录 + 明确的最终状态提示，不再只有 print。
11. SESSION_SECRET 缺失启动失败（fail-fast）。
12. 全站 CSRF token（绑定会话的同步令牌）；delete_org 改 POST+确认页；logout 改 POST；SameSite=Lax+HttpOnly。
13. `next` 只接受以单个 `/` 开头的相对路径。
14. argon2id + 新密码最少 8 位且拒绝纯空白 + 登录限速。
15. 所有 `$filter` 经统一 OData 转义（`'`→`''`）；路径里的 user_id 先做 GUID 校验，非法 400。
16. 配置原子写入（同目录 tmp + `os.Rename`）+ 互斥锁。
18. CSS 按 shadcn 规范重写，补齐模板用到的全部工具类。
19. 删除确认页处理错误响应；许可比率 total=0 显示 `—`；编辑组织密钥留空=保留原值（不再回显）；新用户临时密码改用一次性页面展示（GET /user/{id}/created，会话标记渲染后即失效），不再走 flash cookie；`principalId` 取值全部防御式。

## 分阶段里程碑（每阶段结束 `go test ./...` 全绿）
- **M0**：确认/安装 Go ≥1.22（本机探测在规划模式受限，作为第一步）；建 `go-rewrite` 分支。
- **M1**：脚手架 + config 包（加载/校验/原子写/旧格式迁移）+ 测试。
- **M2**：auth（哈希/迁移/限速）+ 会话 + 中间件 + 登录/登出/改密 + 测试。
- **M3**：graph 包（token、转义、错误契约、分页助手、nextLink）+ RoundTripper 伪传输层测试。
- **M4**：组织与仪表盘 handler + 测试。
- **M5**：用户概况/列表（新分页）/角色筛选/用户详情 + 测试。
- **M6**：用户操作（更新/订阅/删除/新建）+ 后台任务 + 一次性凭据页 + 测试。
- **M7**：shadcn 风格 CSS + 9 个模板全部重写（中文），端到端 httptest 全流程回归。
- **M8**：多阶段 Dockerfile（distroless/static，目标 ~20MB）、compose/.env.example（SESSION_SECRET）、CI 换 setup-go + `go test` + buildx、重写 README 与 AGENTS.md、删除 Python 文件。
- **M9**：19 个问题逐条映射到测试的核对表；本地构建镜像冒烟（Docker 可用时）。

## 行为变化清单（对等之外的刻意修正）
破坏性操作从 GET 改 POST（需确认页）；登出改 POST；删除流程顺序反转；编辑组织密钥留空保留；临时密码一次性页面展示。其余行为与 Python 版对等。
